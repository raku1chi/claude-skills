# アイデアの発想法と組み合わせの例

アイデア出しのときに読む。データは 1 つを眺めるより、共通のキーでつないで「使う人の状況」に合わせたときに価値が出る。ここの例はカタログの「使いどころ」列から取っている。登録・商用の条件は、カタログの該当する行と注記で確かめる。

## 共通キー（データをつなぐ手がかり）

| キー | つなげるもの | カタログの中のデータ |
|---|---|---|
| 住所 → 緯度経度 | 住所しかないデータを地図に載せる、近い順に並べる | アドレス・ベース・レジストリ、ABRジオコーダー、normalize-japanese-addresses、位置参照情報（maps-addresses.md） |
| 郵便番号 → 住所 | 住所の入力を省く | 郵便番号データ、郵便番号・デジタルアドレスAPI（maps-addresses.md） |
| 緯度経度 → 市区町村・小地域・メッシュ | 地点に統計やハザードを重ねる | 国土数値情報の行政区域（maps-addresses.md）、統計GIS の小地域・メッシュ（statistics.md）、J-SHIS の 250m メッシュ（weather-disaster.md） |
| 地方公共団体コード | 市区町村ごとの統計・施設・観光のデータどうし | 全国地方公共団体コード（life-education-local.md）と、e-Stat・統計ダッシュボードAPI・SSDSE などの市区町村別の統計（statistics.md） |
| 法人番号 | 企業の登記・補助金・開示書類・職場情報 | 法人番号、gBizINFO、EDINET、インボイス（法人の登録番号は「T＋法人番号」）、女性活躍DB（business-finance-jobs.md）、介護事業所のデータ（health-welfare-food.md） |
| 学校コード | 学校の情報 | 学校コード（life-education-local.md） |
| ISBN・DOI | 本・論文のメタデータ | NDLサーチ、NDL の書誌データ（culture-research-language.md）、Open Library、Crossref、OpenAlex（global.md） |
| 日付 | 祝日・天気・統計の時系列 | 国民の祝日 CSV（life-education-local.md）、過去の気象データ（weather-disaster.md）、月次の統計（statistics.md） |

キーの形はそろっていないことが多い。全国地方公共団体コードは 6 桁（末尾は検査数字）で、統計では上 5 桁を使うことが多い。住所は表記が揺れるので、つなぐ前に正規化する（ABRジオコーダーなど）。

## 発想の型

| 型 | 考え方 | カタログの例 |
|---|---|---|
| 地図に重ねる | 位置のあるデータを重ねて、その場所の良し悪しを一目で見せる | 物件検索に浸水深を重ねる、災害の種類で絞る避難場所ナビ、近所の生き物マップ |
| 変化を知らせる | 新着・更新・しきい値を見張って通知する | 地域の警報・地震のプッシュ通知、意見募集の新着・締切通知、地域×キーワードの入札アラート、感染症の流行アラート |
| 比べる・順位をつける | 地域・企業・時点を並べる | 市区町村別の人口・物価の推移、人口増減ランキング、働きやすさで企業を比較 |
| 調べる・照合する | 手元の値をマスタと突き合わせる | 郵便番号から住所を自動入力、受け取った請求書の登録番号チェック、社名・住所の自動補完と名寄せ |
| 移動を助ける | 時刻表・現在位置・空き状況を組み合わせる | 乗換案内、遅延のプッシュ通知、空きポートの地図表示、地方バスの時刻表・経路検索 |
| 推計・試算する | 複数のデータから、その人の状況に合わせた数字を出す | 日射量から太陽光発電量を推定、積算温度から収穫期を予測、職種別の年収相場 |
| 学ぶ・楽しむ | 文化・学術のデータを体験にする | 江戸料理のレシピアプリ、くずし字認識の教材、古地図・錦絵の拡大ビューア、用語集・クイズ生成 |
| 仕事を楽にする | マスタや計算を業務に組み込む | 営業日計算、医療事務アプリのコード辞書、給与計算時の最低賃金チェック |

推計・試算で天気そのものを予報するなら、気象業務法の予報業務許可が要る（licenses-and-legal.md）。

## アイデアを広げる問い

- **誰が、どの場面で困っているか**: 引っ越し・子育て・通勤・旅行・災害・就職・開業・介護・学びなど、生活の場面から考えると、使う人と要るデータが決まる
- **何と組み合わせると「自分ごと」になるか**: 自宅の住所、通勤経路、取引先、子どもの年齢、持っている本など、使う人の情報とデータをつなぐ
- **公式サイトが見せていない切り口は何か**: 同じデータでも、地図で・時系列で・比べて・通知で見せると別のアプリになる
- **繰り返し使う理由があるか**: 通知、記録、変化の追跡があると、一度見て終わりにならない
- **期間限定のデータはないか**: 公共交通オープンデータチャレンジのように、コンテストの期間中だけ使えるデータがある（transport.md の注記）

## 組み合わせの例（調査資料より）

データは単独より、住所・緯度経度・法人番号・地方公共団体コードといった共通のキーでつなぐと価値が出ます。代表的な組み合わせを8つ挙げます。

| アプリ案 | 組み合わせるデータ | できること | 気をつけること |
| --- | --- | --- | --- |
| 物件周辺レポート | 不動産情報ライブラリ、ハザードマップのタイル、GTFS・ODPT、医療情報ネット、学校コード | 住所から相場・浸水深・最寄り駅・病院・学校を一画面で表示 | 不動産情報ライブラリのクレジット表示。ハザードは画像タイル |
| 地域比較ダッシュボード | e-Stat API、統計GIS（境界）、住民基本台帳人口、SSDSE | 市区町村を選んで人口・物価・家計を比べ、地図で塗り分け | 統計表IDは基準改定で変わる |
| 取引先チェック | 法人番号、gBizINFO、EDINET API、インボイスWeb-API | 社名から所在地・補助金や受注の実績・財務・登録番号の有効性を確認 | 個人事業者の情報の扱い、クレジット表示 |
| 防災通知Bot | 気象庁防災情報XML、指定緊急避難場所データ、ハザードマップ | 登録地域の警報と、災害の種類に合った最寄りの避難場所を通知 | 独自の予報や「警報」の名乗りはしない |
| 移動ナビ | ODPT、GTFSデータリポジトリ、シェアサイクルのGBFS、OpenStreetMap | 電車・バス・シェアサイクルを組み合わせた経路と空き状況 | ODPTはデータごとのライセンス、OSMはODbL |
| 法令・政策ウォッチ | e-Gov法令API v2、パブリック・コメントのRSS、国会会議録API | 関心のある法令の改正・意見募集・国会での議論を通知 | 法令APIの時点指定は2017年4月以降 |
| 子育て・医療マップ | 医療情報ネット、自治体の子育て施設・AEDデータ、IDWR速報 | 近くの小児科・薬局・保育施設・AEDと、地域の感染症の流行状況 | 自治体ごとに形式が違う。全国AEDマップは許諾なしでは使えない |
| 歴史・文化の学習アプリ | ジャパンサーチ、CODHのデータセット、青空文庫、国立公文書館 | 地域ゆかりの古典籍・文化財・公文書・文学作品を地図や年表で紹介 | 画像は作品ごとのライセンス。CC BY-SAは継承 |
